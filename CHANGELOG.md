# Changelog

## 0.2.0

Added gyro-to-mouse/right-stick aiming, trackpad click-drag mouse/stick/D-pad
modes, optional kernel force-feedback rumble forwarding, desktop settings and
backward-compatible profile settings. Sensor association uses the HID parent.
Rumble effects are stopped/erased on cleanup. Added motion and rumble tests.

Physical controller and Arch installation validation remain outstanding.

## 0.1.0

Initial kernel-backed gamepad bridge, remapping, desktop GUI, profiles, diagnostics,
reconnection, Steam pause and local Arch packaging.
